# Asana and Jam calls

- Name each read's fields. Read templates and the Profile with comments off.
- A task read lists subtask names only; read the bodies you need in one message of parallel reads.
- Activity in a range: one task-list read, completed-since the range start; then comments only for open tasks touched in it.
- Find members, tags and projects with the workspace object search, never the task search.
- Load connector tools in one tool search. Batch creates and updates into one call each.
- Jam: console at error and warn; network with default bodies, no status filter; frames only for a visual defect.
