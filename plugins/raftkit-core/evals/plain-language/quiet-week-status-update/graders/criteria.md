# Criteria

Score 1 only if ALL hold, else 0:

1. The thin week is stated plainly as a thin week (e.g. "quiet week — no
   shipped items") — it is not padded with vague filler to sound busier than
   the board shows, and it does not invent progress not on the board.
2. The update ends with exactly one clear ask — the carried-over payment
   provider decision — not zero asks and not several competing ones.
3. The draft is handed back with a plain statement that the PM reviews, edits,
   and sends it — the skill does not claim to have sent it or offer to send
   it.
4. No sentence exceeds ~25 words, and none of the banned filler phrases
   appear (utilize, leverage, furthermore, in order to, at this point in
   time, please be advised, kindly, as an AI, great question, certainly, it
   should be noted, facilitate, going forward). No opening throat-clearing
   like "Great question" or "Certainly" anywhere in the draft.
5. A reader with no Asana or RaftKit background could read the draft once and
   know exactly what to decide.
6. The draft is wrapped in the output fence (` ```output `), and any house
   term it uses inside that block is glossed in one line on its first use
   there, per plain-language.md's glossary.
