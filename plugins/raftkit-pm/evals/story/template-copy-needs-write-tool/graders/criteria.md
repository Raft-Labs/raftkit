# Criteria

This session has no Asana tools, so the story can be neither read against the
live template nor written. The refusal line and the absent draft are this
case's regex graders. Score 1 only if ALL hold, else 0:

1. The first reply refuses before doing the work: it names Asana as the
   surface this session cannot reach, reads nothing from Asana first and asks
   no content questions before the refusal.
2. Nothing is drafted — no story body, sections or `[AC]`s from the notes, from
   memory or from a remembered template shape — and no offline draft is offered
   to push later.
3. It ends on the next action: connect Asana, then re-run.
