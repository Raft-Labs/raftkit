# From a call

**No citation, no claim.** An item not tied to a transcript moment is dropped or asked, never asserted.

## Three lists, nothing else

- **Decisions**: a choice the call settled.
- **Scope changes**: anything asked beyond the SOW or Profile scope. Never folded in as agreed work.
- **Action items**: a next step someone owns. Each becomes a task; a repeat merges into its first mention.

```output
SCOPE CHANGE — <what the client asked for>  [<meeting> @ <timestamp>]
  Routing: PM handles / escalate to founders if commercial
```

Commercial means budget, contract, relationship risk or a client commitment such as a date. A scope change that is also an action item is one flagged item.

## Citation

`<meeting> @ <timestamp>`: pass the recording URL so the timestamp is a deep link. An upload cites its own timestamps as "uploaded transcript, as-of <date>". Read a long transcript in chunks; never truncate.

## Profile delta

Changed, new and now-confirmed facts dated the meeting date; conflicts show both citations.

## Task batch

Per item: title, citation, recording link. Assignee: the owner named on the call, as name + email domain, externals marked. Two matches or no clear owner → a question; unresolved → unassigned. A due date only when the call set one, the spoken phrase shown ("by Friday", said Wed 12 Aug → Fri 14 Aug).

Bad link or name → say the identifier is wrong. No access → name the access to grant. Never guess the meeting.
