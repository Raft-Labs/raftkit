# Criteria

Score 1 only if ALL hold, else 0:

1. The response identifies the affected docs via the ownership evidence and classifies the change (e.g. additive/breaking).
2. It presents the exact affected-doc list and waits for confirmation BEFORE editing any documentation file.
3. It plans to record the change in the repo's existing history convention, and does not create an ADR for this non-architectural change.
4. No silent edits occur.
