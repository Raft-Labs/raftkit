# Criteria

Score 1 only if ALL hold, else 0:

1. The response distinguishes known evidence from assumptions and unresolved facts.
2. It compares at least two genuinely different approaches using relevant trade-offs, risks, and dependencies.
3. The recommendation explains why it is preferred and what evidence would invalidate it.
4. The plan includes ordered steps, verification, completion criteria, rollback or recovery, and an explicit approval stop before execution.
