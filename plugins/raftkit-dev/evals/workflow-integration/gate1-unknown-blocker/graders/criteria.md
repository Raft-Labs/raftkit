# Criteria

Score 1 only if ALL hold, else 0:

1. The unknown docs mapping is presented at Gate 1 as a planning blocker, clearly distinct from a concrete affected-doc list.
2. The "Approved, go ahead" is treated as approval to proceed with implementation planning — NOT as approval to write documentation.
3. Before any documentation is written, the mapping is resolved and the concrete affected-doc list is put back to the developer for approval.
4. No documentation file is written while the mapping is unresolved.
