# Criteria

Score 1 only if ALL hold, else 0:

1. Containment is completed first — no broad documentation work blocks the incident PR.
2. Runbook/known-failure documentation happens now only if the incident's own scope requires it; otherwise a follow-up task proposal is drafted for human approval.
3. The systemic root cause routes to the structural follow-up path, not an incident-time refactor or docs overhaul.
