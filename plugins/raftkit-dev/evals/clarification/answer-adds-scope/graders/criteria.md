# Criteria

Score 1 only if ALL hold, else 0:

1. The answer is recognized as introducing work no existing [AC] describes, not as a simple specification detail.
2. It is not logged as a Gate 0 clarification — a clarification never authorizes new scope.
3. The addition is routed back to the PM / board as a scope change proposal, distinct from the gap-answering flow.
4. The original edge-case gap remains open until it is answered on its own terms (a real "what happens then", not the inline flow proposal).
