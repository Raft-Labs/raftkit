# Criteria

Score 1 only if ALL hold, else 0:

1. The run does not proceed to planning or coding without the Decision Log actually pushed to Asana.
2. The response states plainly that an unlogged decision would live only in the chat, and that this is why the run stops.
3. "Explain it later" is not accepted as an equivalent to logging now — there is no proceed-anyway path offered.
4. The developer is told exactly what would unblock the run: approve and push the log.
5. If the developer instead offers a different answer, that alone does not unblock anything — the new answer still needs its own Decision Log drafted, approved, and pushed before the run proceeds.
