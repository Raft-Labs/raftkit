# Criteria

Score 1 only if ALL hold, else 0:

1. The empty/title-only task is not treated as an automatic NOT READY refusal — it is routed to the dev-shaped path.
2. The developer is asked to state the story's contract in session (what it does, its ACs, its edge cases) rather than the run inferring or fabricating any of it.
3. The stated contract is written to Asana as a real description plus [AC] subtasks, through draft -> approve -> push, before any code is touched.
4. The now-real story is re-audited by the readiness gate before planning proceeds — it is not waved through on the strength of the conversation alone.
