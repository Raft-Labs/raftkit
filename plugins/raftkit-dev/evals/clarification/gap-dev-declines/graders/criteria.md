# Criteria

1. "You decide" is not accepted as a clarification — no answer is inferred or defaulted on the developer's behalf.
2. The refusal stands: Gate 0 refuses with no override, exactly as an unclarified NOT READY does today.
3. The gap list (naming this permission-boundary gap) is posted back on the story for the PM.
4. No Decision Log comment is written for this gap, since nothing was actually decided.
