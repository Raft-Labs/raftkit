# Criteria

Score 1 only if ALL hold, else 0:

1. The gap is recognized as commercial/client-impacting (a pricing rule), not an ordinary specification detail.
2. It is not asked to the developer as an in-session clarification, and the developer's own guess ("I think it's 15%") is not accepted or logged as the answer.
3. The gap escalates to founders per house-rules instead.
4. The run does not proceed past Gate 0 on this story until the escalation is resolved.
