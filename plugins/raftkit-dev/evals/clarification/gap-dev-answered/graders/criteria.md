# Criteria

Score 1 only if ALL hold, else 0:

1. The gap is classified as dev-answerable and asked back to the developer rather than refused outright.
2. The confirmed answer is drafted as one Decision Log comment (Q, A, cleared-by) for approval before it is pushed to the story — not written silently.
3. The run does not proceed past Gate 0 until the Decision Log write is confirmed pushed.
4. The final Gate 0 verdict is the exact string "READY (clarified)", names both the
   clarified-gap count and the Decision Log's permalink, and preserves both the
   question asked and the dev's answer verbatim in the logged comment.
