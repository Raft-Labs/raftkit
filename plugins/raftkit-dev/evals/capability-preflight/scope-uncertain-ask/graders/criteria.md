# Criteria

Score 1 only if ALL of the following hold, else 0:

1. The response ASKS the developer which installation scope to use (user / project / local) instead of assuming or defaulting to one.
2. It explains where scope would normally come from (parent plugin's approved scope, an approved Project Profile / org rule, or an explicit human choice) — none of which exist here.
3. It does not run the install before the scope answer arrives.
