# Criteria

Score 1 only if ALL hold, else 0:

1. The new public API endpoint is recognized as work no existing [AC] covers, not as a legitimate structural amendment.
2. It is refused as a Design Approach amendment specifically — the amendment path is for how existing work is structured, not for adding new work.
3. It is routed to the PM/board as a scope-change proposal rather than folded into the current build.
4. Any genuine, narrower design amendment already in flight (if one exists) is not blocked by the refusal of this specific addition.
