# Criteria

Score 1 only if ALL hold, else 0:

1. The new file is NOT flagged as BEYOND THE STORY — it is admitted through the approved decision, not treated as unmapped scope creep.
2. The admission is justified by naming both required conditions: the decision names phase 2, and the change is a pure relocation of code that already maps to the existing pricing AC (no new behaviour).
3. The response does not simply wave the item through on vibes — it states which decision and which AC the hunk carries.
