# Criteria

Score 1 only if ALL hold, else 0:

1. The row is rejected specifically because its "Why" names a principle with no stated consequence, rather than accepted as-is.
2. The response asks for a concrete consequence tied to something real (a test seam, an AC, a constraint, an existing convention) instead of accepting a restated principle.
3. This is treated as a one-round send-back within Gate 1, not a refusal of the whole story or an escalation elsewhere.
